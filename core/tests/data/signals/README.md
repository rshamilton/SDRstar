# Small signal files used by the decoder tests

| file | what | origin / licence |
| --- | --- | --- |
| `pocsag1200_22050.raw` | POCSAG 1200 baud pager audio, 22.05 kHz signed 16-bit mono (a real recording) | Converted from `test/samples/POCSAG_sample_-_1200_bps.flac` in the multimon-ng repository (commit 0722194b…), GPL-2.0, the same project whose decoder reads it. Expected: POCSAG1200 messages, e.g. address 273040. |
| `aprs.raw`, `eas.raw` | **Synthetic** AX.25/APRS (Bell 202, 1200 baud) and EAS/SAME (520.83 baud) audio, 22.05 kHz s16 mono | Generated by `tools/gen_afsk_samples.py` from the published encodings (GPL-3.0-or-later, this repository). They prove the decoder wiring and arguments, not RF realism. |

Not committed (no stated licence): `nexus_g027_433.92M_250k.cu8`, a real 433.92 MHz Nexus-TH sensor capture
(250 kS/s, unsigned 8-bit IQ) from rtl_433_tests. Fetch it with `tools/fetch_test_samples.sh`; the ISM test uses it
when present. The tests that need data that is not here report "(skipped)" instead of failing.
